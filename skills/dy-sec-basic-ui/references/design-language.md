# DySec 基础 UI 视觉语言

## 设计目标

- 面向检索、列表、表格、图表、详情、配置和反馈等操作型场景，优先保证扫描、比较、判断和重复操作效率。
- 页面由用户任务、信息层级和数据密度驱动，不做成营销页面或装饰性 Card 集合。
- 默认使用 Light，同时提供完整 Dark；Dark 不是对 Light 的简单反色。
- 视觉规范同时适用于微前端和单体应用内部，不预设宿主能力、产品功能或页面字段。

## 语义 Token

业务代码消费目标项目提供的语义 Token，不直接依赖基础色板，也不复制 Light/Dark 色值。具体值、类型名称和公共 API 以目标项目安装的主题包或设计系统为准。

| 语义 | 职责 |
| --- | --- |
| 品牌 | 品牌识别和少量品牌强调，不替代日常主操作色 |
| 主操作 | 创建、保存、编辑、确认等主要业务操作 |
| 次操作 | 检索、过滤、取消、返回等日常辅助操作 |
| 强调 | 选中标记、焦点环、激活边界等局部强调 |
| 信息、成功、警告、错误、未知 | 对应状态反馈，不互相替代 |
| 文本、背景、边框、浮层 | 表达内容层级和区域关系 |
| 数据可视化 | 图表序列和数据分类，不复用业务操作色充当完整色板 |

- 品牌色、主操作色、状态色和数据可视化色承担独立语义。
- 状态必须同时提供文字、图标或其他可感知信息，不能只依靠颜色。
- 正文链接通过文字样式、上下文和 hover/focus 状态表达可操作性，不强制复用主操作色。
- 不在业务文件中派生或维护另一套主题值；设计系统调整时由主题入口统一生效。

## 密度、排版与分层

- 使用统一间距刻度；团队基础网格为 `8px`，紧密关系可以使用 `4px` 半步，不使用零散 margin 拼接布局。
- 控件高度、字号、字重、圆角和阴影优先使用项目设计系统或 Ant Design Token，不在业务页面创建第二套尺寸标准。
- 页面区块通过背景、弱边框和间距分层；阴影只用于 Dropdown、Popover、Modal 等真正悬浮的内容。
- 相邻区域已经提供内边距时，内部区域不重复叠加同方向间距。
- 工具栏、表单操作区和局部布局保持紧凑，但不能压缩到标签、输入值或操作名称无法辨认。

## 操作与组件层级

- 一个操作区通常只有一个视觉最强的主操作；其他日常操作使用次操作样式。
- 删除、停用等危险操作使用错误语义并配合确认机制，不因为按钮重要就使用危险色。
- 检索、过滤、重置和取消默认属于中性操作，除非业务流程明确把其中某项定义为主要提交动作。
- 内容区不嵌套装饰性 Card；Card 只用于独立重复项、浮层内容或确实需要边界的区域。
- 图表和统计只在帮助解释当前数据或支持判断时出现，不为了填充页面强制添加。
- 组件选型优先复用项目已有组件和 Ant Design 能力，不为轻微视觉差异重复实现基础组件。

## 页面结构与滚动

- 导航、辅助操作和主要内容拥有明确区域；具体功能和位置以目标仓库为准。
- 页面只指定一个主要内容滚动区，避免 `body` 与多个嵌套容器同时滚动。
- 剩余高度布局使用 Flex/Grid，并在可收缩链路中设置正确的 `min-height: 0`；不使用固定 `100vh` 忽略外层布局占用。
- 页面根已经处理内边距、最大宽度或滚动时，业务区域不重复承担相同职责。
- Header、导航、内容和浮层的层级关系明确，避免用不断增大的 `z-index` 修补所有权问题。

### 列表与检索

- 检索条件、批量操作和结果操作按使用频率组织，主要结果区域保持稳定。
- 统计或趋势图表是可选解释层，不阻挡主要检索与结果浏览。
- 表格和分页共享明确的高度与滚动策略；数据量变化时分页和主要操作不应跳动或失去可见性。
- 筛选布局声明合理的最小列宽；空间不足时减少列数或换行，不继续压缩内容。

### 详情

- 概要、状态和主要操作优先出现，相关信息按领域分组。
- 多个稳定子领域可以使用 Tabs；长内容或需要定位时使用页内导航，具体方式由信息关系决定。
- 不为每组字段机械嵌套 Card。
- 返回、编辑、删除等操作位置保持稳定；加载、空数据、部分失败和权限不足使用局部状态表达。

## 自适应与可访问性

- 固定格式控件和工具栏使用稳定高度、最小宽度或 Grid track，减少动态内容引发布局跳动。
- 长文本优先换行、Ellipsis、Tooltip 或调整最小宽度，不按视口宽度缩放字体。
- 浮层使用不透明主题背景、边框和必要阴影，并验证其容器、层级和焦点行为。
- Light/Dark 都检查文本、边框、选中、hover、focus、禁用和滚动条状态。
- 键盘焦点清晰可见；图表、图标按钮和状态标签提供可访问名称或辅助说明。
- 窄视口下优先重排、换行和收起次要内容，不通过水平挤压破坏可读性。
