## 1. 使用方式

本文件给出内部运营和管理后台的框架中立尺寸基线。先读取目标项目已有 Token 和组件库尺寸，建立语义映射；只有缺失角色时才新增 Token。不要为追求字面相同覆盖组件库内部结构或在每个页面复制固定像素。

本文件拥有内部运营和管理后台的科技蓝、画布、工作面、边界、焦点、圆角、紧凑节奏、工具栏、筛选、表单和密度档位。目标项目已有设计系统或组件库时先建立语义映射，再补齐缺失角色；出现冲突时以目标仓库已确认规范为准，不保留两套数值。不要把本文件的产品规则写入跨产品基础 Skill，也不要默认复用于尚未评审的其他产品类型。

## 2. 科技蓝视觉边界

### 2.1 颜色角色

使用以下关系作为浅色主题起点，最终取值由目标项目主题和对比度校准：

| 角色 | 建议方向 | 使用范围 |
| --- | --- | --- |
| 应用画布 | 冷灰蓝，接近 `#f4f7fc` | 页面背景和大面积留白 |
| 工作面 | 白色或极浅冷灰 | 顶栏、侧栏、表单和详情 |
| 主文字 | 深蓝黑，接近 `#0f172a` | 标题、正文、关键数据 |
| 次文字 | 灰蓝，接近 `#475569` | 说明、次要字段、默认导航 |
| 弱文字 | 灰蓝，接近 `#94a3b8` | 禁用和非必要装饰信息；占位、时间与必要辅助元数据使用满足对比度的次文字角色 |
| 主色 | 科技蓝，接近 `#2563eb` | 主要动作、链接、当前项和焦点 |
| 主色弱底 | 主色约 8%–12% 透明度 | 选中、Hover 和非阻塞提示 |
| 结构边界 | 冷灰蓝弱边界 | 控件、区域和分隔线 |

不要沿用橙色主品牌方案。蓝色也不能铺满界面：一个任务区域通常只保留一个实心主动作，当前导航和选中态使用弱蓝底与清晰文字，图表按数据语义分配色阶。

### 2.2 状态与品牌分离

- `primary` 表示品牌主动作和当前焦点，不兼任成功、警告或危险。
- `danger`、`warning`、`success`、`info`、`neutral` 分别定义文字、图标、弱背景和边界角色。
- 高饱和状态色只用于需要立即关注的局部信息，不作为整张卡片或整行的常态底色。
- 状态至少使用文字加颜色；高风险或密集扫描场景追加图标、位置或形状。

### 2.3 层级与材质

- 使用画布、工作面、弱边界和留白建立主要层级；常规卡片无阴影或只有极轻阴影。
- 明确悬浮的菜单、Popover、模态框和抽屉才使用更强阴影。
- 玻璃拟态只可用于不会承载密集正文的顶层辅助区域，并验证对比度、透明背景和性能；不作为数据工作面的默认材质。
- 小控件圆角约 6px，卡片和弹层约 8–12px；不要把 16–24px 大圆角作为后台现代感的必要条件。

## 3. 间距系统

### 3.1 基础刻度

使用 4px 微单位和 8px 主节奏。建议刻度：

| 值 | 典型用途 |
| ---: | --- |
| 2px | 边界微调、角标；不用于独立点击目标间距 |
| 4px | 图标细节、帮助文字间距、同组极近关系 |
| 6px | 图标与短文本、紧凑标签内部；只作为局部半步 |
| 8px | 同组控件、标签与字段、常规行内间距 |
| 12px | 紧凑容器内边距、字段组、工具栏小组 |
| 16px | 默认容器内边距、表单字段、工具栏组 |
| 20px | 默认页面或复杂容器的中等节奏 |
| 24px | 页面区块、页头与主内容、宽松容器 |
| 32px | 大区块、空状态、弹层分区 |
| 40px | 少量强调留白或大型结构间隔 |
| 48px | 页面主要章节，不用于普通卡片堆叠 |
| 64px | 特殊空状态或宽松概览，内部运营页慎用 |

新增间距优先从这组刻度选择。10px、14px、18px 等值只有在组件库既有尺寸、图标光学对齐或明确几何约束下使用，并沉淀为组件 Token，不在页面中反复出现。

### 3.2 关系映射

| 关系 | 紧凑 | 默认 | 说明 |
| --- | ---: | ---: | --- |
| 图标与文字 | 6px | 8px | 图标与标签形成单一整体 |
| 标签与输入框 | 6px | 8px | 保持字段亲密关系 |
| 输入框与帮助或错误 | 4px | 4–6px | 错误出现时不改变字段归属 |
| 同一工具组控件 | 4–8px | 8px | 不同工具组使用更大间隔 |
| 工具组之间 | 12px | 16px | 可加分隔线但不依赖分隔线 |
| 表单字段之间 | 12–16px | 16–20px | 长说明字段取上限 |
| 同一卡片内内容块 | 12px | 16px | 标题与正文按层级选择 |
| 页面区块之间 | 20px | 24px | 重要章节可到 32px |
| 页面水平内边距 | 16px | 20–24px | 宽屏不自动增大，按阅读宽度判断 |
| 卡片内边距 | 12px | 16px | 概览卡或复杂表单可到 20–24px |
| 模态框或抽屉内边距 | 20px | 24px | 固定页脚与正文保持相同对齐线 |

### 3.3 组合规则

- 先用较小间距表达同组，再用至少一个刻度差表达分组。
- 相邻区域已有边界或背景变化时减少额外留白；缺少视觉边界时增加留白。
- 水平工具栏使用 `gap` 管理，不给每个子项散落左右 `margin`。
- 列表和详情的主要对齐线贯穿页头、工具栏和内容，不因卡片内边距反复偏移。
- 避免连续三层容器都使用 16–24px 内边距造成有效空间快速缩小。

## 4. 文字系统

### 4.1 生产型字阶

| 语义 | 字号 / 行高 | 建议字重 | 使用范围 |
| --- | --- | ---: | --- |
| 辅助与字段元信息 | 12 / 16px | 400 | 帮助、时间、单位、次要标注；不承载主要任务正文 |
| 紧凑正文 | 13 / 18px | 400 | 密集列表、工具栏和短字段值 |
| 默认正文 | 14 / 20px | 400 | 表单、详情、说明和常规控件 |
| 字段标签 | 13 / 18px | 500 | 表单标签、筛选名称 |
| 组件标题 | 14 / 20px | 600 | 列表标题、卡片标题、小节标题 |
| 区块标题 | 16 / 24px | 600 | 页面主要分区、详情组 |
| 页面标题 | 20 / 28px | 600 | 工作台或对象页标题 |
| 核心指标 | 24 / 32px | 600 | 少量概览数值，不用于常规正文 |
| 等宽数据 | 12–13 / 18–20px | 400–500 | 标识、地址、代码、日志片段 |

以上尺寸是语义基线，不要求所有项目使用相同 Token 名。内部运营产品采用 14px 生产型正文有助于保持清晰和适度密度；参考 [Carbon productive typography](https://carbondesignsystem.com/elements/typography/type-sets/) 的 14px 基线。

### 4.2 排版规则

- 中文正文和关键字段不使用 10–11px；12px 只用于非关键辅助信息。
- 同一组件最多使用 2–3 个字阶，优先通过位置和字重建立层级。
- 正文使用 400，标签常用 500，标题常用 600；避免 700–800 字重在密集页面大面积出现。
- 中文不通过大写字距或过宽 `letter-spacing` 模拟分组标签；短英文代码可按字体需要微调。
- 数值信息使用一致数字特性；若字体支持，启用等宽数字以稳定对齐。
- 长文或审计说明行高取 1.5 左右，工具栏可使用紧凑行高但不压缩点击区。
- 不以颜色作为唯一层级。弱文字仍必须满足目标对比度，禁用态与只读态不能混淆。

## 5. 控件与目标尺寸

### 5.1 控件高度档位

| 档位 | 高度 | 使用场景 |
| --- | ---: | --- |
| 紧凑 | 28px | 高密度表格行内操作、紧凑筛选条、标签切换 |
| 默认 | 32px | 内部后台默认标准：工具栏、筛选器、搜索框、常规表单和按钮 |
| 舒适 | 36–40px | 登录页、重要独立弹窗表单或极少数强引导操作 |
| 粗指针 | 至少 44px 目标区 | 触控、平板或需要更高容错的关键操作 |

同一工具栏或字段行保持一致高度。默认档 32px 与项目 `@workspace/ui`（shadcn/ui + Base UI + Tailwind）的既有档位直接对应：`sm` 28px（`h-7`）、默认 32px（`h-8`）、`lg` 36px（`h-9`）；`xs` 24px（`h-6`）仅限分段控件内部或行内徽章级微操作，不作为表单与工具栏控件档位。使用其他组件库时映射“紧凑 / 默认 / 舒适”语义并保持整套组件一致，不为获得某个数值单独覆盖组件内部 DOM。

WCAG 2.2 AA 要求指针目标至少容纳 24×24 CSS px，或满足相邻目标间距例外；关键、频繁或难以撤销的操作应采用更大目标。参考 [Target Size (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum) 和 [Target Size (Enhanced)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced)。本基线把 28px 作为密集表格行内操作的紧凑下限、32px 作为默认交互框尺寸，不把 24px 合规最低值当推荐视觉尺寸。

### 5.2 常用控件

| 控件 | 建议尺寸 | 补充规则 |
| --- | --- | --- |
| 文本输入、选择器、日期控件 | 高 28 / 32 / 36–40px | 同一表单统一档位；水平内边距 10–12px |
| 按钮 | 高 28 / 32 / 36–40px | 水平内边距 12–16px；图标与文字间距 6–8px |
| 图标按钮 | 视觉图标 14–18px，按钮框 28 / 32 / 36px | 提供可访问名称和 Tooltip；不只扩大 SVG |
| 多行文本 | 最小高 80–96px | 支持纵向调整或按内容增长；显示字数时预留空间 |
| 复选框、单选框 | 视觉 16–18px，交互框至少 28px | 标签与控件共同可点击，组内间距清晰 |
| 开关 | 视觉约 28–36 × 16–20px，交互框至少 28px | 标签说明当前能力，不把状态只写在颜色上 |
| 分段控件、Tab | 高 32–40px | 选中态、焦点和滚动行为清晰 |
| 菜单项 | 高 28px 紧凑，32px 默认 | 图标、文字、快捷键和子菜单对齐 |
| 标签、Badge | 高 20–24px，字号 12px | 若可点击，外层目标提升到至少 32px |

按钮和输入的视觉规范可按组件库略有不同；稳定的高度档位、文字基线和目标区域比强行统一外观更重要。`@workspace/ui` 的按钮与输入即采用 28/32/36 档位（`h-7`/`h-8`/`h-9`），可直接按 size 变体选用。

## 6. 常见模块尺寸

### 6.1 Shell 和页面

| 区域 | 建议范围 | 说明 |
| --- | ---: | --- |
| 顶栏 | 48–56px | 高频后台优先较紧凑档，并与目标项目 Shell 契约对齐 |
| 展开侧栏 | 216–240px | 文案不截断为首要判断，可允许用户折叠 |
| 折叠侧栏 | 48–64px | 图标点击区和当前态完整，提供可访问名称 |
| 页头 | 最小 48–64px 内容高度 | 标题、状态和主操作对齐，不固定无意义空白 |
| 页面内容内边距 | 16px 紧凑，20–24px 默认 | 大屏保持内容可扫描，不随视口无限增加 |

### 6.2 工具栏和筛选区

- 紧凑工具栏容器高约 40px，默认约 48px；需要换行时由内容决定高度。
- 工具栏控件使用同一高度档，常用动作靠近作用对象，低频动作进入明确菜单。
- 筛选区展开后每行字段保持 12–16px 水平和垂直节奏；不要使用挤压到 24px 高的迷你输入框。
- 已应用筛选摘要和批量栏切换时尽量保持工具区总体高度稳定。

### 6.3 表单

- 紧凑长表单字段间距 12–16px，默认表单 16–20px；分组间距 24–32px。
- 标签与字段间距 6–8px，帮助或错误信息与字段间距 4px。
- 水平表单标签区只在字段短、标签稳定且视口足够时使用；宽度按真实最长标签确定，窄屏切为纵向。
- 双列表单仅用于字段相互独立、阅读顺序明确的短输入；说明长、校验复杂或存在依赖时使用单列。
- 底部操作区与表单主对齐线一致；长页面可固定，但不得遮挡最后字段和错误信息。

### 6.4 卡片、抽屉和模态框

- 常规卡片内边距 12–16px；概览卡和复杂表单容器可使用 20–24px。
- 小型确认模态框常用 400–480px，常规表单模态框 520–640px；更复杂内容升级为抽屉或页面。
- 窄详情抽屉常用 360–480px，中等编辑抽屉 480–640px，复杂详情可到 640–960px，并受视口最大宽度约束。
- 宽度根据内容、视口和背景上下文决定，不把 60%–68vw 或黄金比例当默认规则。
- 模态框和抽屉页头、正文、页脚使用同一 20–24px 对齐线；正文只保留一个主要滚动容器。

## 7. 密度档位

至少定义“默认”和“紧凑”两档，并把差异集中在 Token 或组件变体：

| 维度 | 紧凑 | 默认 |
| --- | ---: | ---: |
| 正文字号 | 13px | 14px |
| 控件高度 | 28px | 32px |
| 卡片内边距 | 12px | 16px |
| 页面内边距 | 16px | 20–24px |
| 字段间距 | 12–16px | 16–20px |

密度切换规则：

- 同一任务区域只使用一个主密度，避免紧凑内容与巨大工具栏并置。
- 紧凑档不低于 13px 主要文字、28px 行内交互框和 WCAG 目标尺寸要求；工具栏与表单主控件保持 32px。
- 触控或粗指针设备自动采用更大目标，而不是沿用桌面紧凑档。
- 用户选择密度时持久化偏好，并保证内容位置、选择、焦点和滚动语义不变。

## 8. Token 骨架

目标项目尚无尺寸 Token 时，可以从以下框架中选取必要角色并按命名约定调整：

```css
:root {
  /* Spacing: 4px micro unit, 8px primary rhythm */
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-5: 20px;
  --space-6: 24px;
  --space-8: 32px;
  --space-10: 40px;
  --space-12: 48px;

  /* Productive typography */
  --font-size-meta: 12px;
  --font-size-body-compact: 13px;
  --font-size-body: 14px;
  --font-size-section: 16px;
  --font-size-page-title: 20px;
  --line-height-meta: 16px;
  --line-height-body-compact: 18px;
  --line-height-body: 20px;
  --line-height-section: 24px;
  --line-height-page-title: 28px;

  /* Control density */
  --control-height-compact: 28px;
  --control-height-default: 32px;
  --control-height-comfortable: 36px;
  --target-size-coarse: 44px;
}
```

颜色角色以本文件第 2 节为产品依据。若组件库已有对应 Token，建立映射而不是重复声明；只有缺失角色时才在目标项目主题层新增变量。

## 9. 视觉验证

### 9.1 源码与组件层

- 定向搜索任意字号、间距、控件高度和橙色品牌字面量，确认它们是必要例外还是应映射 Token。
- 检查同一工具栏和表单是否混用不同高度或字体基线。
- 检查 Hover、Focus、Active、Disabled、Read-only、Error 和 Loading 是否改变布局。

### 9.2 浏览器层

- 使用目标浏览器检查 DOM、computed style 和 `getBoundingClientRect()`，验证实际字号、行高、目标框、对齐和滚动容器。
- 覆盖默认与紧凑密度、100% 与放大缩放、窄窗口、长中文、长英文标识、空值、错误和多行内容。
- 检查固定页头、批量栏、抽屉和模态框是否遮挡焦点或最后一项内容。
- 验证点击区而非仅图标视觉尺寸；相邻小目标不得依赖肉眼估计间距。
- 检查科技蓝面积、状态色强度和对比度，确认主色没有替代状态语义或装饰性泛滥。

无法使用目标浏览器时，只能报告静态与构建证据，不能宣称尺寸、几何或视觉验收完成。
