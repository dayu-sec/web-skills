# 数据录入

## 适用任务

- 表单、筛选区、创建编辑页、批量操作参数、上传、开关、选择器、日期时间输入。

## 常用组件方向

- `Form`：有校验、布局、提交或多字段联动时使用。字段错误要贴近字段展示。
- `Input`、`InputNumber`、`TextArea`：文本、数字和长文本输入。数字范围和单位要清晰。
- `Select`、`TreeSelect`、`Cascader`：枚举、层级和级联选择。选项多时考虑搜索和空状态。
- `DatePicker`、`TimePicker`：时间选择。需要明确时区、范围和默认值语义。
- `Checkbox`、`Radio`、`Switch`：二选、多选和即时开关。危险开关需要确认或可恢复路径。
- `Upload`：文件选择与上传反馈。需要说明格式、大小、进度、失败恢复。

## 选择规则

- 表单先确定用户目标和提交路径，再决定布局、分组、校验和反馈。
- 必填、禁用、只读、加载、提交中、提交成功、提交失败都要考虑。
- 复杂筛选区要支持重置和保持输入可扫描，不把大量字段塞进无组织区域。
- 上传或异步校验要展示进度和失败原因，不吞掉错误。

## 官方资料核对

- 从组件总览定位 Form、Input、Select、DatePicker、Upload、Checkbox、Radio、Switch 等组件。
- 对表单校验、依赖联动、动态字段、上传列表行为不确定时，查看组件级 markdown。

## 应用检查

- 业务表单逻辑保留在对应业务模块，不放进应用壳层。
- 表单草稿、筛选条件、分页和局部缓存属于页面或功能模块的内部状态。
- 组件卸载时清理计时器、订阅、全局事件和临时挂载点。
