# 集成与可靠性

## 外部 HTTP/RPC 客户端

- 为每个外部服务建立独立 client、配置、DTO、错误映射和适配器，避免在业务服务中散落 URL 与协议细节。
- 明确连接、读取、整体调用超时；超时预算小于上游请求总预算并预留本地处理时间。
- 只对幂等操作和明确可恢复错误重试，使用有界次数、指数退避和抖动。
- 区分连接前失败、未知提交结果、上游 `4xx`、限流和 `5xx`；不要无差别重试。
- circuit breaker、bulkhead 和 fallback 按依赖重要性配置；fallback 必须显式标记降级，不能伪造正常数据。
- 上下游字段按已确认契约解析，未知响应进入集成失败路径，不猜多个候选字段。

## 消息与事件

- 事件 schema 包含稳定事件名、版本、事件 ID、发生时间、生产者和业务关联标识。
- 生产者保证数据库与消息的一致性，按风险使用事务 outbox 或平台等价机制。
- 消费者假设至少一次投递，按事件 ID 或业务幂等键去重，并让重试可安全重复。
- 区分可重试、不可重试和毒消息；设置退避、最大次数、DLQ/停车队列和可观测告警。
- schema 演进遵循向后/向前兼容策略，不把 Java 序列化对象当跨服务长期契约。

## 异步、线程池与调度

- `@Async` 方法通过 Spring 代理调用，使用有界线程池、队列、拒绝策略和可识别线程名。
- 在数据库提交后调度依赖该数据的任务；失败状态要可持久化、查询和恢复。
- 异步任务携带必要的追踪与安全上下文，不传递整个请求对象或线程本地状态。
- 调度任务在多实例环境使用锁、租约或幂等扫描；恢复逻辑处理进程中断和租约过期。
- 实现优雅停机：停止接收新任务、等待有界时间、保存可恢复状态。

## 配置与密钥

- 使用 `@ConfigurationProperties` 绑定一组配置，并通过 Bean Validation 在启动时失败；避免散落 `@Value`。
- 配置区分代码默认值、环境覆盖和密钥来源；生产凭据来自 Secret 管理或受控环境，不进入仓库。
- URL、超时、批量大小、线程池和功能开关设置合法范围，启动时校验相互依赖。
- profile 只表达环境差异，不复制整份配置造成漂移；测试 profile 明确禁用不适用的外部初始化。
- 不在错误消息和配置打印中输出密码、Token、证书、连接串或完整请求头。

## 日志、指标与追踪

- 日志记录稳定事件名、业务关联 ID、trace/span ID、结果、耗时和必要计数，不记录完整请求/响应体。
- 在异常所有权边界记录一次堆栈；下层补充上下文后抛出，避免每层重复 error 日志。
- 对敏感标识脱敏或哈希，按数据分类决定是否允许记录。
- 指标覆盖请求量、错误率、延迟分布、依赖调用、数据库池、缓存、消息积压、线程池和任务结果。
- 使用低基数标签；不要把用户 ID、请求 ID、URL 原值或异常文本作为指标标签。
- 跨 HTTP、消息和异步边界传播追踪上下文，记录外部依赖与重试 span。

## 健康与过载保护

- liveness 只判断进程是否需要重启；readiness 判断是否能接收流量，关键依赖按部署策略纳入。
- Actuator 和管理端点单独鉴权、限制暴露并避免返回敏感配置。
- 为入口设置请求大小、并发、队列、查询复杂度和批量上限；过载时快速失败，不让资源耗尽扩散。
- 调用链设计 deadline 和取消传播；任务无法取消时明确记录最终一致性处理。

## 可靠性验证

- 模拟超时、连接拒绝、限流、部分响应、重复消息、进程重启和依赖恢复。
- 验证重试总时长、线程池饱和、fallback 标识、幂等结果和告警触发。
- 验证日志与错误响应不包含敏感字段，指标标签无高基数输入。
