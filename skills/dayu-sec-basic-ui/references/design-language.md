# 基础设计语言

## 1. 视觉方向

基础 UI 使用中性浅色画布、白色工作面和科技蓝主色。蓝色用于主操作、当前导航、焦点环和少量状态提示，不用于大面积装饰。现代感来自稳定网格、紧凑信息密度、克制层级和一致交互，而不是堆叠渐变、玻璃效果或厚重阴影。

## 2. 语义 Token

至少定义以下语义角色，并由浅色、深色主题分别赋值：

- 表面：`background`、`card`、`popover`、`sidebar`、`input`。
- 文字：`foreground`、`muted-foreground`、`primary-foreground`。
- 交互：`primary`、`primary-hover`、`accent`、`ring`。
- 结构：`border`、`sidebar-border`、`input-border`。
- 状态：`destructive`、`warning`、`success`，同时提供文字和弱背景角色。

优先采用接近以下关系的科技蓝浅色基线，而非要求所有项目复制同一字面量：

| 角色 | 建议基线 | 用途 |
| --- | --- | --- |
| 应用画布 | 冷灰蓝 `#f4f7fc` 附近 | 页面背景 |
| 工作面 | `#ffffff` | 顶栏、侧栏、卡片 |
| 主色 | 蓝色 `#2563eb` 附近 | 主操作、选中态、焦点 |
| 主色弱底 | 主色约 10%–12% 透明度 | 选中和提示背景 |
| 主文字 | 深蓝黑 `#0f172a` 附近 | 标题和正文 |
| 次文字 | 灰蓝 `#475569` 附近 | 描述、菜单默认态 |
| 弱文字 | 灰蓝 `#94a3b8` 附近 | 分组标题和辅助信息 |
| 弱边界 | 冷灰蓝约 70% 透明度 | 区域、控件和卡片边界 |

以 WCAG 对比度和目标品牌色校准最终取值。不要只靠颜色传达错误、选中或展开状态。

## 3. 布局与密度

- 顶栏以 48–56px 为常用高度；展开侧栏以 216–240px 为常用宽度，折叠态保持不少于 48px 的点击区。
- 使用 4px 基础步进与 8px 主节奏。页面内容常用 12–16px 间距；高层区域可使用 20–24px。
- 应用根只负责固定视口和区域编排；内容区是主要滚动容器。Flex/Grid 子项在需要收缩处设置 `min-width: 0` 和 `min-height: 0`。
- 窄屏需要明确导航隐藏、折叠或抽屉策略，不依赖内容被动溢出。

## 4. 排版

- 正文和常规控件使用 13–14px；紧凑二级信息可使用 12px；分组标签可使用 10.5–11px 并增加少量字距。
- 页面标题常用 16–20px、600–800 字重；卡片标题常用 14–16px、600–700 字重。
- 正文行高保持 1.5 左右；表格、菜单和工具栏可以更紧凑，但不压缩可点击高度。
- 仅在字体确实随制品加载时声明自定义字体，并提供稳定系统字体回退。

## 5. 圆角、边界与阴影

- 小控件和菜单项使用约 6px 圆角；卡片和弹层使用约 10px；大型容器最多约 14px。
- 默认使用 1px 弱边界。选中态可叠加主色弱底与半透明主色描边，避免高饱和实底占据大面积。
- 常规卡片使用无阴影或极轻阴影；浮层才使用明确阴影。不要用多层阴影弥补层级不清。
- 避免页面容器、区块和字段连续嵌套卡片。优先使用留白、标题和分隔线组织内容。

## 6. 表单与操作

- 紧凑控件高度约 32px，默认约 36px，大尺寸约 40px；同一工具栏保持一致高度。
- 输入框使用工作面或弱输入背景、弱边界和清晰的蓝色焦点环；错误态同时提供文本说明。
- 主按钮保留给页面主要动作；次操作使用弱描边或幽灵样式。危险动作使用独立语义色并要求明确文案。
- 图标常用 14–16px；纯图标按钮的点击区不小于 32px，并提供 `aria-label` 或可见提示。

## 7. 卡片与页面骨架

- 页面骨架优先为“页头/工具栏 + 内容工作面”，而不是每段内容都加卡片。
- 卡片内边距常用 12–16px，卡片间距常用 12px；列表和数据密集页面保持整齐对齐。
- 加载、空、错误和权限状态复用统一骨架，避免页面跳动；状态文案必须说明用户下一步。
- 数据密集视图优先清晰筛选、列层级和固定操作区，不为“现代感”牺牲扫描效率。

## 8. 交互与可访问性

- Hover 使用轻微背景或文字变化；Focus 必须可见；Active 应比 Hover 更明确但不产生布局位移。
- 折叠、展开、选中和禁用状态使用原生属性或 `aria-expanded`、`aria-current`、`aria-disabled` 表达。
- 弹层支持 Escape、点击外部关闭和焦点回收；避免只监听鼠标事件。
- 动效一般控制在 150–250ms，并遵循 `prefers-reduced-motion`。
