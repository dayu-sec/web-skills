# Java Spring Service Development

## 工作顺序

1. 先读取目标仓库全部适用的 `AGENTS.md`，再检查构建文件、Java/Spring 版本、目录结构、配置、数据库迁移、OpenAPI、测试和现有质量命令。
2. 明确本次变更的契约真源、用例、业务不变量、调用方、数据所有权、事务边界、外部依赖和失败语义。
3. 识别仓库采用的分层、六边形或 DDD 边界；在现有边界内做最小修改，不为局部需求发起无关架构迁移。
4. 先设计或更新接口、事件、数据库和外部依赖契约，再实现领域规则、应用编排和基础设施适配。
5. 同步实现校验、错误映射、权限、幂等、并发、超时、日志、指标和迁移，不把它们留到功能完成后补救。
6. 按风险补齐单元、切片、集成、契约、迁移和并发测试，运行仓库实际提供的构建与质量门禁直到通过。
7. 最后复核分层依赖、公开契约、注释、敏感信息、兼容性和运行时配置，交付变更与验证证据。

## 组合规则

- 任务触及 HTTP 端点、OpenAPI、状态码、分页或错误体时，同时使用 `$dayu-sec-rest-api`。
- 已有 OpenAPI、数据库 schema、生成类型、事件或外部服务文档时，同时使用 `$dayu-sec-data-contract-first`。
- 编写、修改、重构或评审代码时，同时使用 `$dayu-sec-code-commenting`，只为公共边界、业务规则和复杂时序补有价值的注释。
- 只处理通用 Java/Spring 服务时不要加载 Web UI 或微前端 Skill。

## 核心边界

- Controller 只处理传输协议、校验触发、身份上下文和响应映射；业务规则留在应用或领域层。
- 应用层编排一个用例并拥有事务边界；领域层表达不变量、状态变化和领域策略；基础设施层实现数据库、消息和外部服务适配。
- 领域层不得依赖 facade、application DTO、JPA 实体、HTTP 客户端或其它基础设施类型。
- 请求 DTO、响应 DTO、领域对象、持久化对象和外部服务 DTO 分离，通过显式转换器跨边界。
- 仓储接口返回领域对象或面向用例的投影；JPA/MyBatis 细节留在基础设施实现。
- 使用构造器注入；避免字段注入、静态服务定位和隐式可变全局状态。
- 只按明确契约处理字段和异常；不要用猜字段、长 fallback 或吞异常制造表面稳定。

## 实现底线

- Java 版本、依赖版本、格式和构建命令以目标仓库为准，不在局部任务擅自升级平台。
- JSON 线上命名与 REST 规范一致，Java 内部保持仓库命名；绝对时间使用 `Instant` 或 `OffsetDateTime` 等有时区语义的类型。
- 事务覆盖完整业务原子边界，外部网络调用默认不持有长数据库事务；异步工作在事务提交后触发并可幂等重试。
- 数据库变更使用版本化迁移；约束、索引、默认值、回滚或前向修复和滚动发布兼容性一起评估。
- 外部调用配置连接与读取超时；只有确认安全的失败才重试，fallback 不得把未知失败伪装成正常业务结果。
- 配置使用类型安全绑定和启动校验；凭据来自受控配置源，不硬编码在代码、默认配置、测试数据或日志中。
- 日志使用结构化上下文，避免打印请求体、凭据、个人信息和完整异常链；指标与追踪覆盖延迟、错误、依赖和队列/线程池状态。
- 公开行为必须有测试；数据库方言、锁、迁移和外部协议使用真实或等价环境验证，不以 H2 通过代替生产数据库语义。

## 评审检查

- 查找反向依赖、跨层对象泄漏、超大 Service/Controller 和重复转换逻辑。
- 查找错误 HTTP 状态、通用成功包装、未校验输入、异常吞噬、敏感日志和过度宽松的 CORS/权限。
- 查找自调用导致的 `@Transactional`/`@Async` 失效、事务中远程调用、无界线程池、无超时客户端和不可控重试。
- 查找 N+1、无界查询、内存分页、缺失索引、错误锁粒度、迁移不可重复执行和多实例竞态。
- 查找只覆盖 happy path 的测试、过度 mock、与生产数据库方言漂移和未验证的 OpenAPI。
- 查找与实现不一致、只复述代码或包含临时信息的注释。

## 输出要求

实现任务交付时至少说明：

```text
仓库依据：AGENTS/build/OpenAPI/现有边界...
契约来源：...
分层落点：facade/application/domain/infra...
一致性设计：事务、幂等、并发、迁移...
失败设计：校验、业务错误、依赖失败...
验证：执行的命令与结果...
未验证风险：无 / ...
```

评审任务只报告问题，不擅自修改；按严重度列出文件和位置、触发条件、影响、依据和最小修复方向。
